**لو ظهر ❌ — لا تُرفع النسخة.**

> بُنيت هذه الأداة بعد خطأ حقيقي: مكتبة QR ضُمّنت مرتين → خطأ صياغة أوقف **كل** الجافاسكربت → تعطلت جميع أزرار الموقع. الأداة أمسكت خطأً مماثلاً لاحقاً قبل الرفع.

## 📐 منهجية العمل

1. **شخّص قبل أن تعدّل** — لا تخمّن السبب
2. **اختبر بمحاكي متصفح (jsdom)** — `node --check` وحده لا يكفي، لأنه يفحص السكربت معزولاً
3. **🔴 تحقّق يدوياً من نتائج الفحص** — الأدوات تعطي إنذارات كاذبة كثيرة (دوال تبدو ميتة لكنها تُستدعى عبر `map`، قيم تبدو غير محمية لكنها ثابتة بالكود). **لا يُعدَّل كود سليم بناءً على نتيجة خام.**
4. **أصلح استباقياً** ما تكتشفه أثناء العمل
5. **بعد كل رفع:** ذكّر المعلم بالضغط `Ctrl+Shift+R` (تحديث قسري)
